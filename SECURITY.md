# Security Policy

## Supported Versions

Currently, only the latest stable version receives security updates.

| Version | Supported |
|---------|-----------|
| latest   | ✅ Yes |
| older    | ❌ No (please upgrade) |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Send details to: **karad120109@gmail.com**

You can expect:
- Acknowledgment within 48 hours
- Update on the fix within 7 days
- Credit for responsible disclosure (if you wish)

Thank you for helping keep this software secure.
